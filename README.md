# 📰 Last News Searcher

**Last News Searcher** es una herramienta sencilla y potente diseñada para obtener las noticias más relevantes publicadas en las últimas 24 horas basándose en una palabra clave específica. Ideal para monitoreo de tendencias, curación de contenido o mantenerse informado en tiempo real.

---

## ✨ Características

* 🔍 **Búsqueda Precisa:** Filtra contenido relevante mediante palabras clave.
* 🕒 **Filtro Temporal:** Resultados estrictamente limitados a las últimas 24 horas.
* 🚀 **Rápido y Ligero:** Diseñado para dar respuestas inmediatas.
